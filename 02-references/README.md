# References

Outside work worth keeping. One folder per reference with numbered captures.

- REF-###-<source>-<slug>/01-<what>.jpg
- Captures: 1440 px wide viewport, saved at 1800 px max, JPEG
- Manifest entry: REF-### with source URL, the note as given, why it's here, elements

Add an entry to `data/manifest.json`, then run `python3 tools/build.py && python3 tools/verify.py`.
