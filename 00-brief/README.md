# Brief

The Google Doc is the source of truth. This folder holds dated text mirrors and, from Wk 2, the locked brief.

- brief-YYYY-MM-DD.md — text mirror of the doc on that date
- brief-locked-YYYY-MM-DD.pdf — the locked version

Add an entry to `data/manifest.json`, then run `python3 tools/build.py && python3 tools/verify.py`.
